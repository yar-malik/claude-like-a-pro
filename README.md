# Claude like a pro: the kit

Everything from the video, so you can copy it into your own business in 10 minutes.

Pine Street Dog Walks is a pretend business. Every file in `example/` except the brain dump and the week's notes was
written by Claude Code on camera.

## What's in here

| File | What it is |
| --- | --- |
| `example/everything-about-my-business.md` | The messy brain dump we started from |
| `example/CLAUDE.md` | The index Claude wrote: one line per file, saying **when** to read it |
| `example/brand/*.md` | Voice, design, audience, offer, story, rules. One fact, one file |
| `example/.claude/skills/weekly-post/SKILL.md` | The skill: week's notes → one Instagram post in your voice |
| `example/posts/` | A post the skill wrote |
| `templates/split-prompt.md` | The prompt that turns your brain dump into the index |
| `templates/7-part-brief.md` | The brief that beat the one-liner |
| `templates/skill-prompts.md` | Make a skill, then improve it with one note |

## The 7 moves

1. Use Claude Code, not just the chat (it's in the Claude desktop app, Code tab).
2. Know which brief you're giving: steps, or an end goal.
3. A tiny CLAUDE.md that works as an index. Plain paths, not `@` imports.
4. Plan first (Shift+Tab to plan mode).
5. The 7-part brief.
6. Bottle what works into a skill. The description says when it fires.
7. Iterate, and put every fix back into the skill.

## Use it

1. Copy `example/` somewhere, delete the dog stuff, and write your own `everything-about-my-business.md`.
2. Open Claude Code in that folder and paste `templates/split-prompt.md`.
3. Make your first skill with `templates/skill-prompts.md`.
