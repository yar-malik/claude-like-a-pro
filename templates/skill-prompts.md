# Make a skill, then improve it

Make it:

```
Make me a skill called weekly-post. Every Sunday I add notes to notes/week.md, and I want one Instagram post from them
in my voice. Save it in .claude/skills/.
```

Type `/week` and it's already in the menu. No restart.

Give a note once, and put it in the skill:

```
Good. One note: end every post with a question to the reader, before the free walk line. Put that in the skill so I
never have to say it again.
```

The finished skill is in `example/.claude/skills/weekly-post/SKILL.md`.
